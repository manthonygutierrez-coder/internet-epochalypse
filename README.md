## How to Play

Six eras of the internet, each one reskinning the world in its own colors, type, and sound as you fly into it. Find the glowing **▶ tags** floating on devices and screens — every one opens a real, working artifact, including **Capsumon**, an original monster-catcher built right into the journey.
